The application covers about **88%** of the full reviewer job (21 done, 2 partial, 2 not done). The PDF editing steps themselves are about **95%** done.

This includes the updated client instructions and the assembly log in logs-updation.xlsx.

**Done**

- Open the Valuation Package by upload or folder path.
- Combine the PDFs into one package.
- Put reports in the required keyword order. The reviewer can still move or remove rows.
- Keep location files together, such as Contribution Analysis Loc 1 then Loc 2.
- Split a multi-page cover into named pages so those pages can be reordered.
- Reorder pages inside a report when the headings match: ADP/ACP (Summary, Detail, Excluded, Corrections), 410(b) (Detail, Excludable, Includable, Summary), and a component Average Benefit Percentage test (Average Benefit Percentage, 401a1 Comp, Gateway, Overall Comp, Rate Group, Sum Comp).
- Save the file as `{Plan number}_{Beginning plan year}-Valuation.pdf`. An off-calendar year uses the plan start year.
- Keep or remove Action Required paragraphs (compliance failure, PRIOR vs CURRENT, after 12 months, top heavy only when the percent is greater than 60, variance, no action). A missing Action Required fact removes that paragraph. A 403(b) package uses ACP wording for the prior-year, current-year, and after-12-month paragraphs.
- Keep CURRENT / PRIOR notices, including the after-12-month versions.
- Fill QNEC and refund amounts, and drop an unused ADP or ACP line.
- Keep ADP and ACP sample letters only when that test failed and returns are required.
- Apply the 402(g) letter rule, including removal when the failure was not processed by 15 April.
- Remove 415 failure information and the 415 letter when the plan did not fail 415.
- Keep Excess Summary for 402(g), 415, or a partially vested ADP/ACP failure.
- Keep or remove Year End Recap bullets.
- Leave a 401(k) BRF report out of the package. The Result Summary line stays, and a 401(k) package does not bookmark BRF. A 403(b) package keeps the BRF report and bookmarks it.
- Add bookmarks, including **HCE** on a 403(b) plan and **ADP Test** / **ACP Test** / **ADP/ACP Tests**.
- Check the cover for company, address, plan name, and plan year end.
- Every Process sets the cover letter date to today and rewrites off-calendar 402(g) dates. When **Retype 402(g) dates and HCE %** is checked, the prior-year HCE % is also rewritten. That box is off by default.
- Read PRIOR YEAR / CURRENT YEAR, future HCE, current HCE, and the allocation answer from the valuation package log Excel. A note that says include contributions, or annual allocation Yes, keeps the contributions wording.
- Remove audited wording, Statement of Contribution, 5500 wording, and escalation wording. A 457 package keeps the Statement of Contribution.
- Highlight rewritten words on the preview. The checkbox can be turned off. The download stays clean.
- Flag Social Security numbers if one is found.
- **Assembly stops** is on by default. A failed required check does not save the PDF, the email draft, or the log.
- Check the Result Summary against the test reports: top-heavy percent (including 0.00% and Plan is / is not Top Heavy), and pass/fail for 410(b), 401(a)(4), 414(s), 402(g), 415, ADP, and ACP. A failed 410(b) also looks for the Average Benefit Percentage wording.
- Check that the three Compliance and Administrative Report pages are present. Missing pages are flagged. They are not created.
- Check the client variance copy: plan number, plan name, plan year end, no Social Security number, zeroes as 0.00, one font size, names as Last, First, and text at the page edge.
- Check plan number and plan name on each report, and plan year end on the excess notice.
- Write the Val Assembly Log in the logs-updation.xlsx columns:
  - Omni Plan Number and Plan Name from the Result Summary.
  - Future HCE and current-year HCE as Yes or No.
  - Allocation as Variance, Annual, or Annual-Var. A true-up with no variance is Variance, with a cell note of 0.00 variance.
  - ADP/ACP, 402(g), 410(b), ABP, 414(s), 401(a)(4), 415, and BRF as P, F, or N/A. Either ADP or ACP failing is F. A test the plan does not have is N/A.
  - Top Heavy as Yes or No.
  - Failed Comp Limit is always N/A.
  - FIS, related plans, MEP, and safe harbor are left blank for the tester.

**Partial**

- Mutual of America stamp is checked. Other company names on the cover are still a visual check.
- An Outlook draft is written with the subject `MOA - plan number - plan name - PYE …`. Rush or Rework is added when the valuation log says so. The reviewer still sends it.

**Not done**

- Claiming the plan on the Testing Log. 
  This is the shared workbook a reviewer opens before assembly and types their name into, so other people can see that plan is already being worked. The requirements point at files such as `MOA 2023 Testing Log.xlsx` and `MOA 2023 Off Calendar Testing Log.xlsx` on the assembly tab under the testing folders. The application does not do this step. It never opens those shared workbooks, it does not know which year’s log or which row is the plan being picked up, and it does not have the reviewer’s name to write into that sheet. The Val Assembly Log that Process writes is a separate file. That one records the finished package. It is not the Testing Log, and filling it does not claim the plan.
- Converting Word, Excel, or image files into PDF. A folder load skips a non-PDF and warns. Dropping a file that is not a PDF or the valuation Excel stops Process. Scanned PDFs that are only pictures also cannot be read, so rules, bookmarks, the filename, and the log stay empty on those packages.
